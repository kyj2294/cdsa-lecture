# 본문 구성 선택

코퍼스에서 목적과 구조가 맞는 개체를 찾으면 그 구성을 먼저 재사용한다. 새로 만들 때만 아래 유형을 선택한다. 같은 장표 안에서도 편집 가능한 PowerPoint 텍스트·표·도형을 유지한다.

|학습 목적|권장 구성|
|---|---|
|개념의 변화 설명|시간축, 전후 비교, 단계 흐름|
|두 접근의 차이|2열 대조, 공통 기준 표|
|여러 도구 비교|편집 가능한 표, 핵심 기준 4~6개|
|업무 절차 설명|번호 흐름, 화면과 단계의 대응|
|원인과 결과 설명|인과 화살표, 좌우 흐름|
|전체 체계 설명|중앙 개념과 연결 관계도|
|판단 기준 제시|2×2 매트릭스, 체크리스트|
|사례 검토|근거 이미지와 짧은 해설|
|장 전환|단원명과 한 문장 목표|

한 장표에는 하나의 설명 목적을 둔다. 읽는 순서가 보이지 않는 카드 나열, 장식용 아이콘 반복, 의미 없는 원형 배치를 피한다. 표가 적합하면 표를 쓰고, 순서가 핵심이면 연결선이 있는 흐름도를 쓴다.

재사용 도식은 원본 연결선의 시작·끝 개체 ID를 새 ID로 함께 바꿔야 한다. 그룹을 해제하거나 스크린샷으로 바꾸지 않는다. 레이아웃별 사용 가능 영역은 `jeju-layouts.json`과 `layouts.md`에서 확인한다.
