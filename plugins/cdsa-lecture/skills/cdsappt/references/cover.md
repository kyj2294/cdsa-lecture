# 표지

표지는 이미지 배경과 편집 가능한 텍스트 레이어로 나눈다. 배경에 제목 글자를 생성하지 않는다.

## 배경 이미지

- 16:9, 최소 1600×900을 권장한다.
- 제목이 놓일 영역은 단순하고 대비가 확보되어야 한다.
- 인물의 얼굴과 핵심 피사체가 제목·로고 영역에 들어오지 않게 한다.
- PNG와 JPEG를 지원한다. 원본 비율이 다르면 중앙 기준 cover crop을 적용한다.
- 생성·다운로드·사용자 제공 여부와 출처를 `assets.json`에 기록한다.

```powershell
python <skill>/scripts/cover_background.py --run <run> --image <file> --source "<source>"
```

## 텍스트 레이어

과정명, 강의 제목, 부제, 발표자, 날짜는 PowerPoint 텍스트로 작성한다. 제목은 실제 배경 위에서 읽히는지 확인하고 필요하면 반투명 면이나 그림자를 사용한다. 긴 제목은 안전 영역과 줄바꿈을 조정하며 작은 글자로 억지로 넣지 않는다.

표지 이미지가 필요 없으면 레이아웃 1의 기본 구성만 사용한다. 이미지 생성 실패 때문에 본문 제작을 중단하지 않는다.
