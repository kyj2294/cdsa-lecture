# 품질 기준

## 자동 검사

- CDSA 슬라이드 마스터가 정확히 하나인지 확인한다.
- 기본 마스터·레이아웃·테마·로고가 `template.pptx`에서 바뀌지 않았는지 확인한다.
- 슬라이드와 개체가 캔버스를 벗어나지 않는지 확인한다.
- 재사용 기록의 원본 ID·파일 해시·개체 ID가 유효한지 확인한다.
- 표 머리글과 짧은 행 라벨의 가운데 정렬을 확인한다.
- 텍스트 상자의 예상 수용량을 넘는 문장을 경고한다.
- 원본 과정명·기관명·날짜와 검색 시 기록한 상단 문구가 본문에 남았는지 확인한다.
- 필수 표·도식이 실제 편집 가능한 PowerPoint 개체인지 확인한다.

재사용 개체는 원본 서체와 색을 유지할 수 있다. 위치·크기·문구를 편집한 사실만으로 실패시키지 않는다.

## 실제 렌더 검토

자동 검사가 잡지 못하는 항목은 Microsoft PowerPoint 렌더에서 확인한다.

1. 상단 강의명·로고·장식과 본문이 겹치지 않는다.
2. 모든 글자가 잘리지 않고 발표 화면에서 읽힌다.
3. 밝은·어두운 레이아웃과 원본 글자색의 대비가 맞는다.
4. 표의 행·열 관계와 숫자 단위가 명확하다.
5. 도식 연결선이 끊기지 않고 읽는 순서가 보인다.
6. 장표의 목적과 문장이 맞고 사실·출처가 정확하다.
7. 시각 자료가 학습에 필요한 정보를 전달한다.

구조 검사 통과는 PowerPoint가 파일을 연다는 뜻이 아니다. 그룹 도형의 연결 ID, DrawingML 자식 순서, JPEG 콘텐츠 형식처럼 PowerPoint에서만 드러나는 오류가 있으므로 실제 렌더를 반드시 실행한다.
